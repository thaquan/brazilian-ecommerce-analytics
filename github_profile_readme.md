## 🚀 Featured Project

### 🛒 [Brazilian E-Commerce Analytics — End-to-End Pipeline](https://github.com/thaquan/brazilian-ecommerce-analytics)
*A production-grade, 4-phase analytics pipeline transforming **100K+ raw marketplace transactions** into strategic business decisions.*

```
 ┌──────────────┐      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
 │   PHASE 1    │      │   PHASE 2    │      │   PHASE 3    │      │   PHASE 4    │
 │  ETL & Clean │ ───> │ SQL Analysis │ ───> │ Star Schema  │ ───> │ Power BI BI  │
 │ (Python/IQR) │      │ (CTEs/NTILE) │      │ (Kimball/Dim)│      │  (DAX/Sync)  │
 └──────────────┘      └──────────────┘      └──────────────┘      └──────────────┘
```

*   **ETL & Preprocessing (Python):** Developed a modular script resolving timezone casting, translating 74 product categories, and using statistical **IQR** to flag transaction outliers—securing 100% GMV financial consistency.
*   **Business Intelligence & modeling:** Restructured flat database tables into a clean **Star Schema (1 Fact, 4 Dimensions)**. Built a contiguous calendar dimension (`Dim_Date`) enabling fast Power BI Time-Intelligence aggregations (YTD, MoM).
*   **Advanced Analytics (T-SQL):** Wrote advanced queries featuring CTEs, Window Functions, and `NTILE(5)` to segment 96,000 customers into **8 RFM behavioral groups** and identified a **Logistics "Fury Threshold"** (customer satisfaction plummeting on 8+ days delivery delay).
*   **Interactive Visuals (Power BI):** Designed a dynamic 4-page executive dashboard featuring global sync-slicers, unified navigation headers, and bookmark-based filter reset controls.
